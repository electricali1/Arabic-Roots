# Arabic Roots Game (لعبة جذور الكلمات)

## Description
A fast-paced word game built with JavaScript, HTML, and CSS. The goal of the game is to test your knowledge of Arabic word roots. Given a list of Arabic words, you must guess the correct root word before time runs out!

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play / User Stories
1. Click the Start button to begin the timer and load the first question.
2. Look at the group of words displayed on the screen.
3. Type the root word in the input box and press Enter.
4. Correct answers increase your score level and add bonus time to the countdown timer.
5. If the timer reaches 0, the game ends. Click Start to reset the game to Level 0.
